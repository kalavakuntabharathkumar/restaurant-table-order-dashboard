# TableFlow — Restaurant Table & Order Management Dashboard

A polished React + TypeScript frontend prototype for restaurant teams. Includes a responsive operations dashboard, order search and status filtering, order creation modal, status progression, summary metrics, and sample restaurant data.

## Requirements
- Node.js 20+ and npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite.

## Production build
```bash
npm run build
npm run preview
```

## Notes
- This is a frontend demo with in-memory sample data. Refreshing the page resets changes.
- The analytics summary uses illustrative demo values; they are not calculated from the seeded order rows.
- Backend, authentication, restaurant tenancy, persistence, and live synchronization are not included.
